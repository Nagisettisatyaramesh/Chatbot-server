Where do I paste this?

Open each .html file on your site and paste the snippet right before the closing </body> tag, near the bottom of the file.
Go to Appearance → Theme File Editor → footer.php and paste the snippet just before </body>. Simpler alternative: install a free "Insert Headers and Footers" plugin and paste it into the footer box — avoids editing theme files directly.
Go to Online Store → Themes → Edit Code → theme.liquid and paste the snippet just before </body>.
In your site settings, look for "Custom Code", "Embed", or "Tracking & Analytics", then paste it into whichever section says it loads on every page (often called "Footer Code" or "Body — End").
